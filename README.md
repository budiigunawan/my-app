# myApp

## Overview

This project is a solution to the Slicing Exercise V4.

- production link: <https://convertium.budigunawan.com>

## Tech Stack

- **Framework:** React.js (with Vite)
- **Language:** TypeScript
- **Styling:** Chakra UI
- **State Management:** useState
- **Routing:** React Router
- **Form Handling:** react-hook-form

## Features

- Login
- Register
- My Profile
  - Basic Details
  - Additional Details
  - Spouse Details
  - Personal Preferences Details
- Edit Profile
  - Basic Details
  - Additional Details
  - Spouse Details
  - Personal Preferences Details

## How to Run Locally

1. **Clone the repository**

   ```bash
   git clone https://github.com/budiigunawan/my-app.git
   cd my-app
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Start development server**

   ```bash
   npm run dev
   ```

4. Open your browser and go to http://localhost:5173 (or as specified in the terminal)
